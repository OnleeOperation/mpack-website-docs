# 09 — Privacy and Safeguarding

M-Pack serves minors. Privacy and dignity are product requirements.

# Core rule

The website tells the story of **M-Pack's work**, not the private histories of individual children.

# Do not publish

- full child names,
- child emails,
- schools,
- home locations,
- family details,
- exact identifying age/location combinations,
- diagnoses,
- ACE history,
- behavioral records,
- case notes.

# Photography / video

Default preference:
- crafts,
- hands,
- materials,
- activity spaces,
- staff/volunteers,
- wide/non-identifying activity shots.

Faces:
- only with documented guardian consent,
- confirm consent covers public web use,
- confirm consent is current.

Never assume an image in an internal document is approved for the public site.

# Stories

Preferred:

> During a recent M-Pack workshop, students practiced patience and collaboration while creating handmade pieces.

Avoid:

> [Name], a 10-year-old who experienced [private adversity], made this craft after struggling with [sensitive issue].

If a featured story is used:
- de-identify when needed,
- remove identifying details,
- obtain approval,
- focus on agency, growth, support, and program context.

# Product pages

Do not:
- name the child who made an item,
- create child seller profiles,
- let buyers message children,
- frame the purchase as "buy from this child,"
- attach the item to private adversity.

Use:
- activity-level story,
- workshop context,
- materials/process,
- mission connection.

M-Pack is the seller.

# Newsletter / forms

Collect minimum information.

Newsletter:
- email,
- optional first name.

Contact:
- name,
- email,
- organization if relevant,
- message.

Do not collect child data through public forms without a protected, approved workflow.

# Analytics

Avoid invasive tracking.

Never send to analytics:
- card data,
- donation notes,
- contact-form contents,
- child identity,
- sensitive program info.

# Impact reporting

Safer examples:
- aggregate activities,
- aggregate participation,
- anonymized highlights,
- approved aggregate outcomes.

High-risk examples:
- child-level behavior scores,
- identifiable case details,
- individual trauma history.

# Storytelling tone

Avoid:
- "broken kids,"
- "saving children,"
- guilt imagery,
- trauma spectacle,
- exaggerated before/after stories.

Prefer:
- agency,
- support,
- relationships,
- access,
- experiences,
- skills,
- resilience,
- community.

# Consent checklist

Before publishing media:

- [ ] M-Pack owns or licenses the asset.
- [ ] Public web use is allowed.
- [ ] If a minor is identifiable, written guardian consent exists.
- [ ] Caption avoids sensitive information.
- [ ] Child is portrayed with dignity and agency.
- [ ] Content would still be acceptable if shared beyond the site.
