# 02 — Source of Truth

This file separates supported project concepts from facts that must be verified before public launch.

## A. Supported by the current class presentation

### Three-stream funding strategy
The presentation recommends:

1. recurring corporate sponsorships,
2. the M-Pack Donors' Club,
3. the M-Pack Crafts Initiative.

### Donors' Club concept
The deck describes the Donors' Club as a monthly giving program designed to create predictable support.

Concept elements in the deck include:

- automatic monthly giving,
- impact reports,
- member newsletter,
- selected perks / crafts / merch,
- multiple giving tiers.

Example prices and membership counts shown in the class deck are **strategy-model values** unless M-Pack approves them for the live site.

### Crafts Initiative concept
The deck describes crafts as coming from existing M-Pack activities such as field trips, workshops, and program activities.

The strategy is:

- use existing programming,
- create tangible craft products,
- promote online,
- sell through community events / online channels,
- build longer supporter relationships,
- connect interested buyers to recurring support.

### Privacy direction already present in the deck
The team's donor-reporting slides already emphasize privacy-first storytelling:

- change names in stories,
- favor activities/hands rather than faces,
- use faces only with written guardian consent.

Apply the same logic to the website.

### Internal-doc rule

Before using information publicly:

- confirm it is current,
- confirm it is intended for public use,
- remove private contact information,

## D. Claims that require verification before launch

- exact official mission statement,
- official legal nonprofit name,
- tax status / EIN language,
- current leadership names/titles,
- active programs and age groups,
- current service area,
- verified impact metrics,
- current partner organizations,
- approved testimonials,
- current donation platform,
- public contact information,
- actual craft inventory and pricing,
- actual merch inventory and pricing,
- shipping/returns policy,
- Donors' Club pricing/perks,
- corporate partnership contact.

## E. Safe default wording

If a fact is not verified, prefer qualitative language such as:

- "M-Pack creates structured experiences that help young people build skills, relationships, and confidence."
- "Monthly support can help M-Pack plan programs with greater consistency."
- "Crafts can be created through M-Pack activities and sold to support future programming."
- "Supporters can stay connected through updates, events, and giving opportunities."

Do not replace missing evidence with impressive-sounding statistics.
