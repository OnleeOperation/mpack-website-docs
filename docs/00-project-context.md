# 00 — Project Context

## The class project

The team is presenting a funding and communication plan for M-Pack.

The presentation frames the problem as unstable one-time support and proposes three complementary funding streams:

1. recurring corporate sponsorships,
2. the M-Pack Donors' Club,
3. the M-Pack Crafts Initiative.

The website should not feel like an unrelated design project. It should act as the **digital infrastructure that connects those recommendations**.

## Current recommendation logic

### Corporate sponsorships
The deck proposes recurring relationships with companies rather than relying only on one-off opportunities. The website should give prospective partners a credible place to understand M-Pack and start a conversation.

### Donors' Club
The deck proposes a monthly giving program that turns one-time support into recurring funding. The website should make recurring giving easy to understand and easy to join.

### Crafts Initiative
The deck proposes:

- creating crafts through existing M-Pack activities,
- connecting crafts to new experiences, skill development, and social engagement,
- promoting crafts online,
- selling through community events,
- turning craft buyers into longer-term supporters.

The website is especially valuable here because it can make the craft strategy visible and actionable.

## Why a website is a useful deliverable

The website can show, in one place:

- what M-Pack does,
- why the work matters,
- how supporters can stay informed,
- how donors can give monthly,
- how supporters can shop crafts/merch,
- how companies can partner.

The site therefore turns the deck from a recommendation into something M-Pack could actually use.

## Product idea in one sentence

**Create one digital hub that moves visitors from awareness to engagement to recurring support.**
